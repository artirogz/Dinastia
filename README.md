# Платформа курсов в Telegram — стартовый пакет

Здесь архитектура, модель данных, правила и рабочий процесс для платформы онлайн-курсов в Telegram
(Mini App + бот с прогревами и оплатой). Кода приложения ещё нет: он создаётся Claude Code по этим
документам.

## Как начать (macOS)

Нужен только установленный Claude Code. Остальное ставит сам Claude.

1. Распаковать пакет в пустую папку проекта (например, `~/Projects/courses-tma`).
2. Открыть эту папку в терминале (или в VS Code), запустить `claude`, подтвердить доверие папке.
3. Вставить стартовый промпт:

   ```text
   Начинаем работу над проектом. Это стартовый пакет: прочитай CLAUDE.md и PROJECT-STATE.md и действуй по скиллу start-project. Сначала проверь и доустанови окружение на этом Mac (Homebrew, Node 22 или новее, Git, Docker через OrbStack), сделай git init и первый коммит, потом задай мне все стартовые вопросы одним сообщением и собери каркас приложения до первого скриншота. Если чего-то не хватает и это могу сделать только я, назови ровно одну команду или действие и жди.
   ```

Дальше Claude проверит Homebrew, Node, Git и Docker и поставит недостающее, сделает `git init` и первый
коммит, задаст вопросы (бот, домен, сервер, ЮKassa, видеохостинг), создаст структуру, поднимет базу в
Docker и сделает первый скриншот приложения. Руками на чистом Mac понадобится: ввести пароль при
установке Homebrew и Command Line Tools (установщики спрашивают сами, установка CLT идёт несколько минут),
один раз подтвердить запуск OrbStack в его окне, вписать значения в `.env.local` (Claude назовёт переменные,
секреты он не читает) и, если Git ещё не настроен, назвать имя и почту для коммитов. Остальное Claude делает сам.

Скриншоты макетов можно положить в `design/screens/` сразу или позже (как их называть — `design/README.md`);
Claude спросит про них на старте и вернётся к ним на этапе экранов.

## Что внутри

| Путь | Что это |
|---|---|
| `CLAUDE.md` | инструкция для Claude Code: что читать, какие правила, какие команды |
| `docs/00…12-*.md` | архитектура, данные, вход и безопасность, оплата, видео, бот, экраны, этапы, сервер, работа с Claude, решения, операционка владельца после запуска |
| `PROJECT-STATE.md` | живое состояние: открытые вопросы, блокеры, журнал |
| `design/` | скриншоты макетов и токены дизайна |
| `content/courses/example-course/` | пример курса файлами (yaml + markdown) |
| `infra/` | docker-compose, Caddyfile, пример `.env`, скрипты деплоя и бэкапа |
| `scripts/` | скриншоты экранов (Playwright), проверка прода |
| `.claude/skills/` | рабочие процедуры: старт проекта, роутер задач, визуальная проверка, приёмка, Telegram Mini App, ЮKassa, деплой |
| `.claude/agents/` | дешёвый агент поиска по коду и рабочий агент реализации |
| `.claude/settings.json` | разрешения для Claude Code, чтобы не подтверждать каждую команду |
